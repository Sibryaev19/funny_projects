# Запуск на Windows (10 и 11)

Python в PATH не нужен — все скрипты работают через `.venv` в корне проекта.

## Первый раз на машине

1. **`install.bat`** — найдёт Python (PATH → `py` → реестр → ручной ввод),
   создаст `.venv`, поставит зависимости из `requirements.txt`.
2. Скопируйте `.env.example` в `.env` в корне проекта и настройте:
   сетка, ячейка, цвета, пауза, `FPS`, папки `DEFAULT_FOLDER` и `OUT_DIR`.
   Эти же значения передатчик и приёмник подхватывают автоматически.
3. **`preflight.bat`** — проверит импорты и сделает тестовый снимок экрана.
   Если вердикт «ВСЁ ГОТОВО» — машина умеет в захват.
4. **`test_all.bat`** — прогонит все тесты (~10 сек).

## Повседневный запуск

| Файл | Что делает |
|---|---|
| `start_transmitter.bat` | Сервер + открывает страницу передатчика в браузере |
| `start_receiver.bat` | Приёмник с настройками из `.env`; окно с кадрами должно уже мерцать. Доп. флаги можно дописать: `start_receiver.bat --debug` |
| `test_all.bat` | Все тесты |
| `preflight.bat` | Проверка машины |

## Нюансы

- Окно с кадрами держите на **главном мониторе** (приёмник снимает только его).
- Брандмауэр при первом запуске спросит про python — разрешить (сервер
  слушает только 127.0.0.1).
- Результат приёма — в `OUT_DIR/<дата-время>/` (по умолчанию `received/<дата-время>/`).
- Если передача сыплет ошибками CRC — увеличьте ячейку на странице передатчика
  (правило: физический размер ячейки на экране ≥ 3 px).
