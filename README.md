# funny_projects

Коллекция моих pet-проектов на Python.

## Проекты

- **[img_translator](img_translator/)** — визуальный канал передачи данных
  через экран: передатчик рисует закодированные цветные кадры (web-страница
  в браузере), приёмник снимает экран и декодирует обратно в файлы.
  Передача проверена бит-в-байт на объёмах до 3.4 МБ.
  Подробности — в своём README.

## Общее

- Каждый проект — самодостаточная папка со своим README и `requirements.txt`.
- Зависимости ставятся в виртуальное окружение проекта (`.venv/` — в игноре).
- Личные настройки — через `.env` (шаблоны — в `.env.example`, сами `.env`
  в репозиторий не попадают).
