# funny_projects

Небольшие pet-проекты на python решающие весьма специфичные задачи, которые показались мне весьма интересными

## Проекты

- **[img_translator](img_translator/)** — визуальный канал передачи данных
  через трансляцию экрана
- **[shit_downloader](shit_downloader/)** — качальщик публичных папок с
  Яндекс.Диска. Создан из чистой ненависти: Яндекс отключил скачивание
  архивом в веб-интерфейсе, и этот скрипт существует, чтобы об этом не думать.
  Качает всё содержимое папки (рекурсивно, с вложенными подпапками) одной
  командой через официальный публичный API — без токенов, без веб-интерфейса,
  без унижения от кликанья по файлам по одному.
