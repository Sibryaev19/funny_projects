# user_tests

Тесты, делегируемые пользователю. Протокол: агент пишет скрипт + команду запуска,
пользователь выполняет и присылает вывод в чат.

Делегировать стоит не только рабочие проверки (корпоративная Jira, Windows),
но и любые, где запуск руками дешевле токенов агента (например, тесты UI) —
решает агент по соотношению цена/польза.

Правила: скрипты самодостаточные (одна цель), печатают результат в stdout,
зависимости — только стандартная библиотека, если возможно.
Конфиг пользователь правит в одном месте — .env проекта (скрипты ищут его вверх по папкам).
