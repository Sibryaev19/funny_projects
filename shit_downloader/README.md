# shit_downloader

Скачивает публичную папку (или отдельный файл) с Яндекс.Диска одной командой.
Использует официальный открытый метод API `GET /v1/disk/public/resources`,
поэтому работает независимо от ограничений веб-интерфейса (токен не нужен).

## Возможности

- рекурсивный обход папки, включая подпапки; структура каталогов сохраняется;
- параллельное скачивание (5 потоков) с повторами при сбоях;
- повторный запуск не перекачивает уже скачанные файлы.

## Использование

Требования: Python 3, `requests`.

```bash
python3 ydisk_dl.py <ссылка_на_публичную_папку> [папка_назначения]
```

Пример:

```bash
python3 ydisk_dl.py https://disk.yandex.ru/d/xxxxxxxx laba
```

Перед скачиванием скрипт выводит список найденных файлов и структуру каталогов.
По умолчанию файлы сохраняются в `yandex_dump/`.
Если ссылка указывает на одиночный файл — скачается только он.
